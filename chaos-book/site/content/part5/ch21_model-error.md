## Overview

Everything so far has assumed a perfect model and imperfect initial conditions. Drop that and the picture changes: model error does not grow the same way initial-condition error does, it does not saturate at the same level, and it cannot be reduced by better observations. Stochastic parameterisation is the standard response, and the chapter is honest about how partial a response it is.

## The planned notebook

Forecast Lorenz 96 with a deliberately wrong forcing $F$, and separate initial-condition error from model error in the same experiment.
